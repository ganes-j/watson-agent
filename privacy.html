Privacy Policy

Watson Agent. Effective 2 September 2026.

1. Scope of this policy

This policy covers Watson Agent, a private automation assistant operated by a single individual for that individual's own accounts. Watson Agent has one user, who is also its operator. Watson Agent is not offered to the public and collects no data from anyone other than its operator.

2. Google user data that Watson Agent accesses

Watson Agent requests two read-only Google OAuth scopes:

  • https://www.googleapis.com/auth/gmail.readonly, which permits reading mail messages and their metadata.
  • https://www.googleapis.com/auth/calendar.readonly, which permits reading calendar events.

Watson Agent requests no other Google scopes. These scopes grant no ability to send, modify, label, move, or delete anything in a Google account.

3. How Watson Agent uses the data

Watson Agent uses this data for one purpose. It answers questions its operator asks about the operator's own mail and calendar. Examples include finding a message, summarising a thread, and reporting what is scheduled.

Watson Agent does not use Google user data for advertising. Watson Agent does not sell it. Watson Agent does not use it to build profiles of other people. Watson Agent does not use it to train any machine learning model.

4. Limited Use

Watson Agent's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Where processing happens

Watson Agent interprets requests with a language model that runs locally, on hardware the operator owns. Google user data is not sent to any third-party model provider, and it is not sent to any external service.

Message content and calendar content stay on the operator's own machine. They are read from the Google API, held in memory or in local storage for the duration of the task, and then discarded.

Watson Agent may use external model providers for tasks that involve no Google user data. Those tasks never receive mail content, calendar content, or any data derived from them.

6. Storage and retention

Watson Agent stores its OAuth refresh tokens on hardware the operator owns and controls. Access tokens are short-lived and are held in memory or in the same local store.

Watson Agent does not keep a copy of the operator's mailbox. It reads from the Google API when it needs an answer. Any working copy created to answer a question is temporary and is discarded.

Conversation records held by Watson Agent may quote parts of a message. Those records live on the operator's own hardware and are deleted when the operator deletes them.

7. Sharing

Watson Agent shares Google user data with nobody. There are no model providers, no analytics services, no advertising networks, and no other recipients.

8. Human access to the data

The only human who reads this data is the operator, who is also the account holder. No employee, contractor, or other person has access.

9. How to revoke access

The operator can end Watson Agent's access at any time. Go to myaccount.google.com/permissions, select Watson Agent, and remove access. Revocation takes effect immediately and applies to all data, past and future.

10. Data deletion

To delete data held by Watson Agent, the operator deletes the local token store and the local conversation records. Because Watson Agent keeps no server-side copy, no further deletion request is needed.

11. Security

Tokens are stored on an encrypted disk on hardware the operator controls. Watson Agent holds read-only scopes, so a compromise of the host cannot be used to send mail or alter a calendar.

Changes are published on this page with a new effective date.
