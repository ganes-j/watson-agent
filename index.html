Watson Agent

A private automation assistant, operated by one person for their own accounts.

What this is

Watson Agent is a personal software assistant. It runs on hardware owned by its operator. It reads the operator's own Google mailboxes and calendars so it can answer the operator's questions about them.

Who can use it

Watson Agent has one user: its operator. It is not offered to the public. It has no sign-up, no accounts, and no customers.

What it accesses

Watson Agent requests read-only access to Google account data through two scopes:

  • gmail.readonly for reading mail
  • calendar.readonly for reading calendar events

Watson Agent cannot send, delete, or change anything in a Google account. The read-only scopes make those actions impossible, not merely forbidden.
